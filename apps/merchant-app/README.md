# 🏪 TurboPay Business - Merchant Portal

Frontend portal for merchants using the TurboPayment ecosystem. Built with Next.js 14 App Router, NextAuth, and Tailwind CSS.

## Features
- **Merchant Authentication**: Business ID and password authentication via NextAuth Credentials provider.
- **Merchant Dashboard**: Real-time metrics on available balance, locked funds, and settlement counts.
- **Request Money**: Issue payment requests / invoices to customers by user identifier.
- **Settlement Tracking**: Monitor real-time status of customer payments (`Processing`, `Success`, `Failed`).

## Local Development
Runs on port `3000` by default:
```bash
npm run dev
```
Access at [http://localhost:3000](http://localhost:3000).
